# Problem content

Add audited problem records using the project Problem schema. Preserve exact source numbering and section labels. Do not publish guessed statements or solutions.

Each record should include:
- Stable problem ID
- Course ID and one or more topic IDs
- Exact source section, question number, and PDF page when confirmed
- Original statement and answer choices
- Given values, target quantity, and required assumptions
- Numbered solution steps and final answer
- Related calculator IDs
- Difficulty only when justified
- Verification status and reviewer notes
