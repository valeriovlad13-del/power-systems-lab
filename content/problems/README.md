# Problem content

Maintain question records using the project's typed problem schema. Preserve stable IDs, original section labels, question numbers, statement wording, and answer choices.

Each record should include:
- Stable problem ID
- Course ID and one or more topic IDs
- Original section and question number
- Problem statement and answer choices
- Given values, target quantity, and required assumptions
- Numbered worked-solution steps and final answer when verified
- Related calculator IDs
- Verification status and reviewer notes

Keep the source-marked answer separate from the independently verified answer. Leave a problem pending if data, units, assumptions, or answer choices are ambiguous or inconsistent. Do not publish guessed statements or solutions.
